# AvatarForge — Worklog

Project: Free AI Avatar Generator & AI Profile Picture Platform (Next.js 16 hash-routed SPA, Tailwind 4, shadcn/ui, z-ai-web-dev-sdk for real AI generation).

## Architecture decisions (main coordinator)

- Single Next.js route (`/`) renders `src/components/App.tsx`, a hash-router SPA (`src/lib/router.tsx`). "Pages" = components under `src/components/pages/` mapped from hash paths like `#/ai-avatar-generator`.
- Real AI generation: `POST /api/generate-avatar` uses `zai.images.generations.edit` (photo → styled avatar). No fake demo results.
- Design: violet/fuchsia SaaS theme (no blue/indigo), light+dark mode, sticky footer (`min-h-screen flex flex-col` + `mt-auto`), mobile-first.
- Shared helpers: `@/lib/router` (Link/useRouter), `@/lib/seo` (useSeo), `@/lib/site`, `@/lib/types`, `@/lib/avatar-styles` (STYLE_GROUPS + customization options), `@/lib/gallery-data`.
- Shared components: `@/components/shared/PageHero`, `@/components/shared/CTABanner`; layout in `@/components/layout/{Header,Footer,CookieNotice}`.
- Site imagery generated by AI into `public/images/avatars/` (10 fictional portraits + og-image + icon).
